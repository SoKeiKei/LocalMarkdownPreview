# 性能报告

测试日期：2026-08-27  
测试系统：Windows 11 家庭中文版 x64，版本 10.0.26200  
构建：Visual Studio 2022 `v143`，Release x64

## 结果

| 项目 | 需求目标 | 本机结果 | 结论 |
|---|---:|---:|---|
| 100 KiB 文档解析 | 冷启动不超过 700 ms，热启动不超过 250 ms | 多轮 Release 组件测试约 2–5 ms | 通过，组件数据；真实 Explorer 视觉启动未单独计时 |
| 1 MiB 文档解析 | 不超过 1.5 s | 多轮 Release 组件测试约 20–37 ms | 通过 |
| 500 次组件解析私有占用增长 | 不超过 20 MiB | 950,272 字节 | 通过 |
| 真实 Explorer 宿主私有占用 | 目标不超过 50 MiB，硬上限 80 MiB | 2,822,144 字节 | 通过 |
| 真实 Explorer 宿主工作占用 | 参考值 | 21,372,928 字节 | 通过 |
| 真实 Explorer 连续切换 500 文件 | 增长不超过 20 MiB且保持响应 | 17.0 秒；私有占用减少 24,576 字节；同一进程保持响应 | 通过 |
| Release DLL | 轻量 | 258,048 字节 | 通过 |
| 安装目录 | 不超过 25 MiB | 约 4.1 MB，19 个文件 | 通过 |
| 安装包 | 不超过 10 MiB | 约 1.9 MiB | 通过 |

## 方法说明

文档解析测试在 `MarkdownDocumentTests` 中使用固定生成的 100 KiB 和 1 MiB Markdown，并在同一测试中执行 500 次解析后读取进程私有占用。它测的是核心读取后的解析与格式生成，不包含 Explorer 进程启动和安装成本。

真实切换测试在专用资源管理器窗口中生成 500 个中文 Markdown 文件，逐个选中并等待预览消息处理。切换前后读取同一个专用低权限 `prevhost.exe` 的私有占用、工作占用、句柄数和响应状态。

## 边界

没有执行连续两小时等待测试；该项保留为未验证。100 KiB 冷/热 Explorer 端到端时间没有专用跟踪工具证据，因此只将组件数据用于证明解析余量，不把它描述为严格的 Explorer 冷启动测量。
