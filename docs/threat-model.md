# 威胁模型

## 保护目标

- Markdown 内容不能执行脚本、命令、HTML 事件或外部程序。
- 预览不能访问网络，也不能根据文档内容启动子进程。
- 图片只能读取 Markdown 所在目录及其子目录中的安全本地文件。
- 恶意大文件、图片炸弹和异常嵌套不能无限消耗宿主资源。
- 安装与卸载不能静默接管或破坏用户已有的预览选择。

## 输入边界与处理

| 风险输入 | 处理 |
|---|---|
| 原始 HTML、`script`、`iframe`、事件属性 | MD4C HTML 回调直接丢弃，不进入显示或执行环境 |
| `javascript:`、`data:`、`file:` 链接 | 仅作为不可点击文字，不导航 |
| HTTP/HTTPS 远程图片 | 拒绝，不联网 |
| 绝对路径、UNC、设备名、`..` 图片 | 拒绝并显示占位 |
| 符号链接或检查后替换 | 以最终文件句柄取得规范路径并确认位于文档根；从同一句柄读入内存后解码 |
| 图片伪装和损坏数据 | 同时检查扩展名、文件签名、WIC 解码结果、尺寸和像素预算 |
| 超大 Markdown | 超过 5 MiB 立即拒绝 |
| 深度嵌套或极端节点 | 节点、输出和 1.2 秒解析预算，且每次回调检查取消状态 |
| 大图或大量图片 | 单图编码、边长、像素、解码内存和文档总量均有限制，最多 20 张 |
| 写入或目录输入 | 只读打开并拒绝非普通文件 |

## 进程隔离

安装器登记专用 `Prevhost.exe` AppID，不写 `DisableLowILProcessIsolation`。真实 Explorer 测试确认宿主完整性 RID 为 `0x1000`。插件没有网络组件、遥测、日志、服务、计划任务、启动项或自动更新。

实际恶意样本包含脚本、事件、iframe、危险链接、远程图片、父目录、绝对路径、UNC 和数据图片。预览后专用宿主保持响应，TCP 连接数为 0，子进程数为 0。

## 安装边界

安装需要一次管理员确认以写入机器级 COM 登记。发现已有预览处理器时提供替换、保留或取消选择。安装前把相关原值写入 UTF-8 无 BOM 备份；卸载只恢复仍由本项目占用的映射，避免覆盖用户之后的选择。

专用清理工具只处理名称为 `prevhost.exe` 且模块列表中包含安装目录内精确 DLL 路径的进程。它不会结束 Explorer，也不会处理其他预览宿主。

## 残余风险

- 未签名安装包仍依赖用户核对 SHA-256 和可信传输渠道。
- WIC 属于 Windows 系统解码边界；本项目通过低权限宿主、格式白名单和严格预算减小影响，但不能替代系统安全更新。
- Windows 10、其他 Windows 11 版本、ARM64、两小时长测和全部 DPI/主题组合尚未获得实机证据。
