# 已知限制

- 当前只提供 x64，未提供 ARM64 或 x86。
- Windows 10 22H2 是支持目标，但没有对应实机或干净虚拟机证据。
- 安装包是开发版且未签名，Windows 可能显示未知发布者提示。
- 链接为了安全只显示，不支持点击打开。
- WebP 是否可显示取决于系统是否安装对应 WIC 解码器。
- 透明图片插入 RichEdit 后的背景融合由系统位图显示能力决定，复杂透明边缘可能与网页阅读器略有不同。
- 超过 5 MiB 的 Markdown、超过预算的图片、损坏编码或解析超时会显示简短错误，不做部分渲染。
- 当前账户没有创建符号链接的权限，因此目录重解析逃逸用例由实现检查和普通路径测试覆盖，但该自动用例在本机跳过。
- 已完成真实 500 文件连续切换，没有完成连续两小时长测。
- 已验证当前 Windows 11 暗色 Explorer 的真实预览，以及自动化亮色、暗色和高对比度调色板；没有更改用户系统主题做真实亮色截图，也没有覆盖多显示器、所有缩放比例和所有高对比度组合。
- 项目没有自动更新。升级需要用户运行新的安装包。

这些限制不影响当前 Windows 11 x64 上的基本安装、格式化预览、本地图片、复制、低权限隔离和卸载恢复。
