# 测试样本说明

`corpus` 中只保存 UTF-8 无 BOM 的固定样本：

- `basic.md`：首版基础语法、中文、Emoji、表格、任务列表和本地图片。
- `security.md`：脚本、危险链接、远程资源、绝对路径、父目录穿越、UNC 和数据 URI。
- `edge-cases.md`：未闭合语法、长词、深层列表、不存在图片和混排。

UTF-8 BOM、UTF-16、GBK、GB18030、损坏编码、1 MB、5 MB、超限文件、超长单行和图片炸弹样本由测试脚本在 `artifacts` 下临时生成。这样既能覆盖编码测试，又不会破坏仓库“所有已提交文本均为 UTF-8 无 BOM”的规则。

所有安全样本只允许进入本项目自己的解析和显示测试，不得交给浏览器、脚本解释器或外部程序。
